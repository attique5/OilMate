# OilMate

**Smart Maintenance. Better Performance.**

OilMate is a modern Android application designed to help vehicle owners track engine oil changes and manage maintenance schedules. With a clean and intuitive interface, OilMate makes vehicle maintenance simple and convenient.

## Key Features

- Engine oil change tracking.
- Oil change reminders and notifications.
- Mileage and service interval tracking.
- Last and upcoming oil change dates.
- Daily maintenance reminder notifications.
- Vehicle service history.
- Clean and modern user interface.
- Lightweight application design.

## Designed For

- Personal vehicle owners
- Daily commuters
- Car enthusiasts
- Professional drivers
- Commercial vehicle owners

## Download & Installation

1. Download `OilMate.apk` from the Releases section.
